# v2 改进计划（2026-10-10，根据用户试玩反馈）

游戏名：**小龙大胃王 / Dragon's Appetite**（「龙游天海」作废：以后可能加别的龙，名字不绑天和海；西方龙，不用「化龙」这类仙侠名）。

用户反馈（原话要点）：
1. 手感偏难，经常和要吃的擦肩而过。
2. 美术可以更精致：场景和 UI 都是。需要 3D / 2D 资源就用 AI 做。
3. 三个年纪体验没有区别：技能没增加，也没变得更好捕猎。

## 1. 捕猎手感（sim 负责）

| 机制 | 做法 |
|---|---|
| 自动瞄准 | 前方锥角内（幼 32° / 少 38° / 成 44°）、距离内（火龙 30/38/46 米，海龙 22/28/34 米）挑一只能吃的猎物「锁定」（`S.hero.lock`），转向和俯仰自动往它偏；玩家用力往反方向拖时让位。界面在被锁定的猎物上画一个小圈 |
| 扑咬 | 锁定的猎物进入「扑咬距离」（嘴半径 × 3 + 速度 × 0.15）且在 50° 内：头往前一探，0.15 秒内吸进嘴里 |
| 一口吞几只 | 吃到一只时，嘴边的其他猎物一起吞（幼 1 / 少 2 / 成 4 只） |
| 威压 | 半径内（幼 0 / 少 8~10 / 成 16~22 米）的猎物吓呆：不逃、速度降到 30% |
| 擦肩率指标 | 机器人统计「进入嘴边 1.5 倍吸附范围、又没被吃掉就离开」的次数 / 进入次数；目标 ≤ 30% |

## 2. 每个阶段的新能力（进化时弹「新能力」卡）

| | 幼龙 | 少年龙 | 成龙 |
|---|---|---|---|
| 火龙 | 咬、喷火（短程 9 米） | **扎水**（往下用力拖冲进海里抓鱼；幼龙往下拖只会贴着海面拉起）；喷火 17 米、烤得更快；一口 2 只 | **龙吼**（第二个按钮，冷却 10 秒：42 米内的猎物全被吼晕 4 秒，多吃一档；天敌逃跑）；**大口吞**（一口 4 只）；喷火 24 米 |
| 海龙 | 咬、冲刺（0.8 秒） | **跃出**（在水面往上拖就冲出水面抓鸟；幼龙到水面只会贴着游）；冲刺 1.2 秒；一口 2 只 | **漩涡**（第二个按钮，冷却 10 秒：34 米内的鱼 2.5 秒内被吸到嘴边）；**大口吞** |

另外每个阶段：嘴更大、吸附范围更大、能吃的档位更高、天敌从追你变成躲你（已有）。

小目标按新能力重排（`config/dragons.js` GOALS）：幼龙学咬和喷火 / 冲刺；少年龙第一个目标就是用新学会的扎水 / 跃出；成龙第一个目标是用龙吼 / 漩涡吃 5 / 8 只。

界面：进化时的「新能力」卡（图标 + 名字 + 一句话）；成长条上显示「下一阶段能学会什么」（灰色图标）；成龙多一个技能按钮（在动作键上方，外圈显示冷却）；锁定圈。

## 3. 美术

- 场景：岛换成 AI 出概念图 → Tripo 智能网格的精模（火山、绿岛、石柱，各 1~2 个变体），卡通着色 + 描边；碰撞剖面从模型实测；天空和云更精致（AI 画的云贴图）；海面更卡通；镜头不再钻进山和水下岩壁。
- UI：AI 做标题字「小龙大胃王」、图标（能力、阶段、按钮），统一画风；HUD 在手机上更大更清楚。
- 生物：放大一点、轮廓更清楚。
- 主角：补幼龙 / 少年海龙模型（Tripo 流程）。
- 进化闪光改成金色轮廓光，不再把龙刷成白色。

## 4. 验收

- 机器人：每档擦肩率 ≤ 30%；幼→少 60~120 秒，少→成 150~240 秒（中速档）。
- 录像（带界面，`rec3d.py --dom`）：每个阶段都能看到新能力被用出来；镜头不穿山；HUD 清楚。

## 5. 第二轮反馈（2026-10-11）

- 「刚变成成龙游戏就结束了，很尴尬」→ 进化到成龙不再弹结算卡；成龙有自己的三个小目标，做完才弹「大胃王！」结算卡，之后继续自由玩、补图鉴。
- 「少年体没增加技能」→ 用户选了「把成龙技能提前」：少年龙就得到技能按钮（火龙「龙吼」/ 海龙「漩涡」，范围小、冷却 12 秒）；成龙升级为「大龙吼 / 大漩涡」（范围大、冷却 8 秒）+「大口吞」。始终只有一个技能按钮。
- 两口之间加「嚼」的停顿（幼 0.35 / 少 0.2 / 成 0.1 秒），海龙幼龙不会一秒吸光整个鱼群。
